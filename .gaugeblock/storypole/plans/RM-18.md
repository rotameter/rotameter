# RM-18 Execution Blueprint: `0.3.0` Web UI

Canonical specification: `docs/SPEC-UI.md`, `docs/SPEC-API.md` (§7), and `ADR-0009`.

## Implementation Phases
1. **Backend & Auth (`RM-37`):** `GET /v1/capabilities`, optional cluster fields on `POST /v1/query` `meta`, `/v1/auth/*` (`HttpOnly; SameSite=Lax; Secure` sessions + CSRF, local admin, OIDC, CF Access / Bearer passthrough), and Cargo feature `ui` embedded static asset serving (`--ui=on|off`, default `off`, plus `--ui-dir`).
2. **Frontend Foundation (`RM-38`):** Bun workspace monorepo under `ui/` (`apps/web`, `@rotameter/ui`, `@rotameter/plugin-sdk`), `tokens.css` (Drafting Vellum / Avionics Night / 3 densities), `@base-ui/react` + Base UI shadcn escape hatch, TanStack Router/Query URL state, capability handshake, and auth gate.
3. **Core Analytics Plugins (`RM-39`):** Lazy-loaded `@rotameter/plugin-overview` (`uPlot` + KPI strip), `@rotameter/plugin-breakdowns` (TanStack Table + Virtual reading `--density-table-row-h` + CSV/Parquet export), and `@rotameter/plugin-realtime` (5m active + 30m pulse).
4. **Ops/Admin Plugins & Gates (`RM-40`):** `@rotameter/plugin-admin` (sites & API keys), `@rotameter/plugin-cluster` (single-node health & ingest-only role status), WCAG 2.2 AA verification, and bundle-size gates (`<= 250 KB` gzip initial load, `<= 1.5 MB` embedded `ui/dist/`).

## Non-Negotiable Invariants
- Strictly `/v1/*` and `snake_case` JSON; visitor collection (`collect.js`, `pixel.gif`, `/v1/events`) remains 100% cookieless.
- Zero hardcoded colors, drop-shadows, or pixel row heights; zero ECharts in `0.3.0`; zero WebGL dependencies.
- Local `self_site` dogfooding respects `--no-self-site` and never phones home.
