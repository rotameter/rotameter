# RM-37 Design Blueprint: Backend Capabilities, Auth & Feature-Gated UI Serving

Specs: `docs/SPEC-UI.md` (§1, §4), `docs/SPEC-API.md` (§7), `ADR-0009`.

## 1. `GET /v1/capabilities` & `POST /v1/query` Cluster Metadata
- Add unauthenticated `GET /v1/capabilities` returning `snake_case`:
  `{ topology: "single", node_role: "all"|"ingest"|"query", features: { ui, arrow_export, oidc, streams }, auth_methods: [...], endpoints: { query: "/v1", stream: "/v1" } }`.
- Extend `QueryMeta` (`POST /v1/query` `meta`) with optional `watermark_ts: Option<String>`, `partial_nodes: Option<u32>`, and `served_by_node: Option<String>` (`skip_serializing_if = "Option::is_none"`).

## 2. Operator Auth (`/v1/auth/*`)
- Endpoints: `POST /v1/auth/login`, `POST /v1/auth/logout`, `GET /v1/auth/me`, `GET /v1/auth/oidc/start`, `GET /v1/auth/oidc/callback`.
- Local admin credentials (hashed password / bootstrap config) and OIDC/SSO issue `HttpOnly; SameSite=Lax; Secure` (when HTTPS/public-url is https) session cookies with CSRF double-submit or Origin/Sec-Fetch-Site verification on mutating routes.
- Accept operator sessions, trusted Cloudflare Access headers/JWT, or `rm_adm_`/`rm_rd_` Bearer tokens on query/admin routes.
- **Invariant:** Collection routes (`/v1/collect.js`, `/v1/pixel.gif`, `/v1/events`) never read or set cookies.

## 3. Feature-Gated Static Asset Serving
- Add Cargo feature `ui` in `rotameter-server` and `rotameter-cli` embedding pre-compressed `ui/dist/` (`<= 1.5 MB` compressed) via `include_dir` or `rust-embed` (keeping `#![forbid(unsafe_code)]`).
- CLI/env/config: `--ui=on|off` (default `off`), `--ui-dir <path>` runtime override (works even without `ui` Cargo feature), SPA fallback to `index.html` for non-`/v1/*` routes, immutable cache headers for hashed `/assets/*`, `no-cache` for `index.html`.
- Keep all `.rs` files `< 250` lines (split `auth_session.rs`, `handlers/auth.rs`, `handlers/capabilities.rs`, `ui_assets.rs`).
