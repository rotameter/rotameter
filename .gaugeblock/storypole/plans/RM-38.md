# RM-38 Design Blueprint: Bun Workspace Monorepo & Host Shell

Specs: `docs/SPEC-UI.md` (§1, §3, §4, §5, §6), `ADR-0009`.

## 1. Bun Workspace Layout (`ui/`)
- `ui/package.json` (`"workspaces": ["apps/*", "packages/*"]`), `ui/tsconfig.base.json` (`"strict": true`).
- `ui/packages/ui` (`@rotameter/ui`): `tokens.css` (exact Drafting Vellum light, Avionics Night dark, and compact/standard/comfortable density tokens), Tailwind v4 CSS entry, `@base-ui/react` wrapped primitives (`Button`, `Input`, `Select`, `Popover`, `Dialog`, `Drawer`, `Tabs`, `Tooltip`, `InstrumentFrame`), and `components.json` for Base UI-backed shadcn escape hatch.
- `ui/packages/plugin-sdk` (`@rotameter/plugin-sdk`): `PluginManifest` (routes, nav_items, dashboard_panels, visualizations, inspector_tabs, row_actions, query_transforms, exporters, scopes), `useDashboardQuery()`, `updateQuery()`, `ChartHost` (deferred WebGL seam), `useCapabilities()`, and typed `/v1/*` fetch client with `AbortSignal` + configurable `query_base_url`/`stream_base_url`.
- `ui/apps/web`: Vite + React + TypeScript host compiling to static `ui/dist/`.

## 2. State, Routing & Boot Handshake
- Boot calls `GET /v1/capabilities`; if `node_role === "ingest"`, gate query routes and route to Node Role Telemetry view.
- Auth gate calls `GET /v1/auth/me` and renders login/OIDC screen when unauthenticated.
- `@tanstack/react-router` validates canonical search params (`/sites/:siteId/overview?range=7d&interval=1h&compare=prev&f=country:US,path:/blog/*`) with `push` for discrete pivots and `replace` for continuous adjustments.
- `@tanstack/react-query` keys off validated URL query (`staleTime` 30–60s historical, `AbortSignal` wired).
- `localStorage` persists `theme`, `density`, sidebar collapse, and stream pause state.
- Compact header telemetry strip renders `SINGLE-NODE · <query_ms>ms` (extensible for cluster lag / partial shard).
