# RM-39 Design Blueprint: Core `0.3.0` Analytics Plugins

Specs: `docs/SPEC-UI.md` (§2, §3, §5, §6, §7), `ADR-0009`.

## 1. `@rotameter/plugin-overview`
- Lazy-loaded Vite chunk registered via `PluginManifest` (`scopes: ["read:aggregates"]`).
- Renders 6-metric CAD KPI instrument strip (`visitors`, `pageviews`, `visits`, `views_per_visit`, `bounce_rate`, `avg_visit_duration_ms`) with period comparison deltas and AAA `>= 7:1` primary numeral contrast in tabular monospace.
- Renders `uPlot` time-series inside `ChartHost` (zero ECharts, zero WebGL): reads `--series-*` and `--border-hairline` from CSS tokens, combines colorblind-safe hues with distinct stroke dash patterns (`solid`, `6 3`, `2 2`) or markers, supports brush zoom (`replace` history), and provides a keyboard-accessible tabular data fallback view.

## 2. `@rotameter/plugin-breakdowns`
- Tabs for Pages (`path`), Referrers (`source` / `channel`), UTM/Cohorts (`utm_*`), and Devices/Geo (`country`, `region`, `browser`, `os`, `device`).
- Uses `@tanstack/react-table` + `@tanstack/react-virtual` with owned HTML/SVG proportion bars (no ECharts).
- Virtualizer `estimateSize` reads `--density-table-row-h` dynamically via `getComputedStyle` + `MutationObserver` on `data-density` for `O(1)` scroll offset math.
- Row click pushes filter pills via `updateQuery()` (never `window.location`).
- Includes CSV (`POST /v1/query` `format: "csv"`) and Parquet export actions (gated by `capabilities.features.arrow_export`).

## 3. `@rotameter/plugin-realtime`
- Polls `GET /v1/sites/{site}/realtime` via TanStack Query (`staleTime` 5–15s, `AbortSignal`).
- Displays 5-minute active visitor readout, active pages table, and 30-minute minute-by-minute pulse (`uPlot` or owned SVG bar strip with tabular fallback).
