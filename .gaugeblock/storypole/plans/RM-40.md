# RM-40 Design Blueprint: Admin & Cluster Plugins + WCAG 2.2 AA & Bundle Gates

Specs: `docs/SPEC-UI.md` (§1, §4, §6, §7), `AGENTS.md` (§3.6), `ADR-0009`.

## 1. `@rotameter/plugin-admin`
- Lazy-loaded workspace plugin (`scopes: ["admin:sites", "admin:keys"]`).
- Site management over `/v1/admin/sites*`: create/edit `slug`, `display_name`, `timezone`, `salt_rotation`, `respect_gpc`, `allowed_origins`, `allowed_query_keys`, `raw_retention_days`, plus confirmed delete (`?confirm=true`) and `collect.js` snippet generator.
- API key management over `/v1/admin/keys*`: mint scoped keys (`ingest`, `read`, `admin`) with one-time plaintext reveal/copy modal, list metadata, and revoke keys.

## 2. `@rotameter/plugin-cluster`
- Single-node health & role status panel over `GET /v1/health` + `GET /v1/capabilities` (queue depth `%`, storage readiness, schema version, uptime, active `node_role`).
- Acts as the default landing view when `node_role === "ingest"` (Node Role Telemetry status view).
- Keeps clean extension seam for `0.5.0` (`RM-22`) multinode roster grid when `topology === "cluster"`.

## 3. Automated Quality, Lint & Bundle-Budget Gates
- Add lint rules banning hardcoded hex/rgb colors, blurred box-shadows, hardcoded pixel row heights, raw `window.location` in `packages/plugin-*`, ECharts in `0.3.0`, and WebGL deps.
- Add automated WCAG 2.2 AA verification (token contrast assertions, `:focus-visible` ring, `>= 24×24px` target sizes in `compact` density, chart tabular fallback accessibility).
- Add `scripts/check-ui-budget.sh` asserting initial load `<= 250 KB` gzip and total compressed embedded `ui/dist/` `<= 1.5 MB`.
